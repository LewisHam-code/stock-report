# 安装与运行

## 环境

- Python 3.12，浏览器；正式解读需要网络及使用者自己的模型账户。
- Node.js 仅用于 JavaScript 开发测试，日常使用不需要。
- 已在 macOS 验证本地启动；Linux、Windows 的全部流程未验证。后台使用 `fcntl` 等 Unix 能力，原生 Windows 不列为首版支持平台。
- 不要求 Obsidian、Apache、Docker 或独立数据库服务。

## 先看只读演示

```sh
python3 tools/serve.py --demo
```

访问终端显示的本地地址。演示使用 `examples/demo-site`，不读真实数据库，不初始化密钥，不执行模型调用，写接口返回只读提示。页面上的保存、收藏、运行按钮不会修改数据。

## 正式本地运行

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r research-data/requirements.lock
python tools/serve.py
```

首次启动由模板生成被 Git 忽略的 `research-data/automation.json` 并创建空 SQLite 数据库。界面、API 均由同一个回环服务提供，默认端口 8876。按 `Ctrl+C` 停止；不安装任何系统启动项。

### 配置模型

1. 打开“设置 → 模型配置”，填自己的密钥。
2. 读取可用模型，选文本生成模型；按需要选择财务提取、精读用途，保存并勾选启用。
3. 检查每日调用上限和单份预估费用上限，然后手动运行一次研究流程。
4. 观察数据来源、运行状态、报告与追踪页面；缺数据时保留待核实状态。

密钥也可通过环境变量或 `.env.local` 提供。空 `.env.example` 不是可用凭证；“检查连接”和读取模型列表也会访问所选服务商，连接检查可能产生少量计费。

自动运行默认关闭。前台模式开启后按设置间隔执行，关闭终端服务就停止；没有承诺睡眠、断网或余额不足时仍能工作。停止进程时如有付费请求正在处理，应先等待本轮完成，避免重复调用和结算未知。

### 端口冲突

```sh
python tools/serve.py --port 18876
```

网页和 API 同源，换端口无需修改前端。不占用其他安装实例的端口或系统任务。若使用 CLI 的后台自动启动逻辑，须同步设置环境变量 `STOCK_PORT`；默认仍为 8876。

### macOS 系统定时任务（可选）

这是明确的持久化安装操作，常规前台启动不会执行。需要关闭终端后继续运行时，先停止前台实例，再在本项目虚拟环境内执行：

```sh
python research-data/run.py install-service
```

随后在本机设置页启用定时任务。任务名称与其他安装版本隔离；只适用于 macOS 用户会话，电脑仍需登录、联网、唤醒。服务安装路径由当前项目位置生成，移动目录前先停用对应任务。首版没有提供一键卸载器，原生安装流程没有在本次准备工作中实际注册验证。

## 常见问题

- **缺少 Python 包**：确认已激活虚拟环境，按锁定依赖安装；包下载失败时检查当前 Python 版本与软件源。
- **没有报告**：首次安装数据为空；先配置模型并运行。没有新公告、来源故障、未启用模型、证据不足或费用超限都会影响解读。
- **无完整评分**：因子缺失不等于公司得零分；查看覆盖率、未知区间与证据。
- **跨年行情停止自动刷新**：检查 `job_schedule.py` 交易日历覆盖；首版静态日历不承诺自动覆盖未来年份。
- **备份**：不要将密钥、真实数据、原始响应、账单或归档提交到 Git；参见架构文档。

安装说明未要求调用收费模型来验收。本次实际验证范围见 `VALIDATION.md`。
