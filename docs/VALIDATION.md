## 可复现命令

在独立虚拟环境内：

```sh
PYTHONPATH=research-data python -m unittest discover -s research-data/tests -p 'test_*.py'
node --test research-data/tests/*.cjs
python tools/smoke_test.py
python tools/check_release.py
```

`smoke_test.py` 在临时副本启动演示与空数据库模式，完成后关闭自己创建的服务；不访问外部行情或模型接口。原环境凭证的精确匹配检查是本地私密验收步骤，真实匹配值和原目录信息没有写入开源资料。
